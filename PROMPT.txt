1. Register users (PIC_DAPUR, PIC_SEKOLAH, DRIVER)
2. Create Dapur → Create Sekolah
3. Link Sekolah to Dapur (supply chain)
4. Assign Driver to Dapur
5. Monitor system-wide operations
6. Respond to tickets
```

### 🟢 PIC_DAPUR (Kitchen Manager) Flow

**Primary Responsibilities**: Kitchen operations, menu planning, food preparation, and delivery dispatch

**Daily Workflow**:

**Morning - Menu Planning & Preparation**:
1. **Check Menu Planning** (`GET /api/menu-planning`) - Review weekly menu schedule
2. **Create/Update Menu Harian** (`POST /api/menu-planning/:planningId/menu-harian`) - Define today's menu with:
   - Menu name, cooking times
   - Nutritional information (calories, protein, carbs, fat)
   - Cost per tray
3. **Manage Inventory** (`GET /api/stok`, `PATCH /api/stok/:id/adjust`) - Check ingredient availability and adjust stock levels
4. **Manage Kitchen Staff** (`GET /api/karyawan`) - Assign tasks to employees

**During Cooking - Checkpoint Tracking**:
5. **Create Checkpoints** (`POST /api/menu-harian/:menuHarianId/checkpoint`) with photos:
   - `MULAI_MEMASAK` - Start cooking (with photo)
   - `SELESAI_MEMASAK` - Finish cooking (with photo)
   - `PACKING` - Food packing (with photo)

**Before Delivery - Dispatch Management**:
6. **Check School Attendance** (`GET /api/sekolah/:sekolahId/absensi/total/:tanggal`) - Determine quantity needed
7. **Create Pengiriman** (`POST /api/pengiriman`) - Generate delivery with:
   - Target school
   - Number of trays based on attendance
   - Number of baskets/containers
   - **QR Code automatically generated**
8. **Assign to Driver** - Driver receives QR code for scanning

**Key Features for PIC_DAPUR**:
- Photo verification at each cooking stage
- Real-time inventory management
- Automatic QR code generation for deliveries
- Track delivery status through driver scans

### 🔵 DRIVER Flow

**Primary Responsibilities**: Transport food from kitchen to schools with QR-based tracking

**Delivery Workflow**:

1. **View Assigned Deliveries** (`GET /api/driver/pengiriman`) - See today's delivery schedule
2. **Get Delivery Details** (`GET /api/pengiriman/:id`) - View:
   - Destination school
   - Number of trays/baskets
   - QR code information
3. **At Kitchen - Pickup Scan** (`POST /api/pengiriman/:qrCodeId/scan-driver`):
   - Scan QR code when picking up food
   - System records `waktuScanDriver` (pickup timestamp)
   - Confirms food has left the kitchen
4. **During Transport** - Navigate to destination school
5. **At School - Delivery Scan** (`POST /api/pengiriman/:qrCodeId/scan-sekolah`):
   - School staff scans the same QR code
   - System records `waktuScanSekolah` (delivery timestamp)
   - Confirms successful delivery
   - Calculates total delivery time

**QR Code System**:
- Each delivery has a unique QR code ID
- Driver scans FIRST (pickup confirmation)
- School scans SECOND (delivery confirmation)
- Both scans required to complete the delivery cycle

### 🟡 PIC_SEKOLAH (School Manager) Flow

**Primary Responsibilities**: School administration, student management, attendance, and receiving deliveries

**Daily Morning Routine**:

1. **Record Class Attendance** (`POST /api/kelas/:kelasId/absensi`):
   - Enter number of students present per class
   - System calculates total school attendance
   - This number determines food quantity needed

**Student Management**:

2. **Manage Students** (`POST /api/sekolah/:sekolahId/siswa`) - Add students with:
   - Personal info (name, NIS, gender, age)
   - Physical measurements (height, weight)
   - **System auto-calculates IMT (BMI) and nutritional status**
   - Upload student photo
3. **Manage Allergies** (`POST /api/siswa/:siswaId/alergi`) - Record student allergies for safety
4. **Organize Classes** (`POST /api/sekolah/:sekolahId/kelas`) - Create and manage class structure

**When Food Arrives**:

5. **Scan QR Code** (`POST /api/pengiriman/:qrCodeId/scan-sekolah`):
   - Receive delivery from driver
   - Scan QR code to confirm receipt
   - System logs delivery time
   - Completes delivery tracking chain

**Monitoring & Reporting**:

6. **View Menu Planning** (`GET /api/sekolah/:sekolahId/menu-planning`) - See upcoming weekly menus
7. **Check Delivery History** (`GET /api/sekolah/:sekolahId/pengiriman`) - Track all deliveries
8. **Review Attendance History** (`GET /api/sekolah/:sekolahId/absensi`) - Analyze attendance patterns
9. **Monitor Student Nutrition** - View IMT and nutritional status for health tracking

**Support**:
10. **Create Tickets** (`POST /api/tickets`) - Report issues or request assistance
```
